# Prysm Glitch Trade

Prysm is a marketplace for PC builders, gamers, and tech enthusiasts to trade
computer hardware.

## Firebase setup

The app uses Firebase Email/Password Authentication. Create a Firebase project,
enable Email/Password under Authentication, then run:

```sh
flutterfire configure
```

This generates the platform configuration needed by `Firebase.initializeApp()`.
Run the app with `flutter run` after configuration.
